## Задача 3.10. Угадайка
### Текст задачи
Дана сигнатура метода: `public void guessGame();`  
Необходимо сгенерировать случайное число от 0 до 9, считывать с консоли введённое пользователем число и выводить, угадал ли пользователь.

### Код метода
```java
public void guessGame() {
    int number = ThreadLocalRandom.current().nextInt(0, 9 + 1);
    int cnt = 0;
    while (cnt >= 0) {
        System.out.print("Введите число от 0 до 9: ");
        while (!scanner.hasNextInt()) {
            System.out.println("Это не целое число!");
            scanner.next();
        }
        int x = scanner.nextInt();
        cnt++;
        if (x == number) {
            System.out.println("Вы отгадали число за " + cnt + " попыток!");
            cnt = -1;
        } else {
            System.out.println("Вы не угадали, введите число от 0 до 9: ");
        }
    }
}
```

### Алгоритм решения
1. Сгенерировать случайное число `number` от 0 до 9.
2. Счётчик попыток `cnt = 0`.
3. В бесконечном цикле:
   - считать число `x`;
   - увеличить `cnt`;
   - если `x == number`, вывести сообщение об успехе и количество попыток, выйти из цикла;
   - иначе вывести сообщение о неудаче и продолжить.

### Алгоритм решения
1. Создать новый массив `new_arr` той же длины.
2. Для `i` от 0 до `arr.length - 1`:
   - `new_arr[i] = arr[arr.length - 1 - i]`.
3. Вывести полученный массив.
